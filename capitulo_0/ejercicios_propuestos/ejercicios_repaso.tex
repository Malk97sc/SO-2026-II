\section*{Introducción}
El siguiente taller tiene como objetivo integrar los conceptos fundamentales vistos en el Capítulo 0: paso de parámetros por línea de comandos, gestión de memoria dinámica y manipulación de archivos. Los problemas planteados requieren un análisis detallado de la estructura de datos y una gestión responsable de los recursos del sistema.

\section*{Ejercicio 1}
Diseñe un programa que genere en memoria dinámica un tablero de caracteres alternados. El programa debe recibir por línea de comandos dos enteros positivos $N$ y $M$, y dos caracteres $A$ y $B$.

\textbf{Ejemplo de ejecución:} 
\begin{lstlisting}[numbers=none]
$ ./tablero 4 5 X O
\end{lstlisting}

\textbf{Ejemplo de salida:}
\begin{lstlisting}[numbers=none]
X O X O X
O X O X O
X O X O X
O X O X O
\end{lstlisting}

\textbf{Requerimientos:}
\begin{enumerate}
    \item El programa debe validar que se pasen los 4 argumentos necesarios.
    \item Debe reservar memoria dinámica para una matriz de caracteres (\texttt{char **}) de tamaño $N \times M$.
    \item Rellene cada posición con $A$ o $B$ según la paridad de la suma de sus índices.
    \item Implemente una función \texttt{print\_matrix} y una función \texttt{free\_matrix} para gestionar la limpieza.
    \item El programa debe imprimir la matriz en pantalla.
    \item La matriz creada debe ser dinámica, es decir, debe poder aceptar cualquier valor de $N$ y $M$ e imprimir correctamente el patrón.
\end{enumerate}

\section*{Ejercicio 2}
Diseñe una herramienta que procese un archivo de texto con registros de envíos. La primera fila del archivo contiene un valor $n$ que indica la cantidad de registros. Cada línea representa un envío con el formato:

\begin{lstlisting}[numbers=none]
<ID_ENVIO> <DISTANCIA_KM> <PESO_KG>
\end{lstlisting}

\textbf{Ejemplo de comando:} 
\begin{lstlisting}[numbers=none]
$ ./envios input.txt 15
\end{lstlisting}

\textbf{Ejemplo de salida esperada (Peso superior a 15 kg):}
\begin{lstlisting}[numbers=none]
1024 38.5 16.0
1025 12.0 20.5
1026 92.0 18.0
\end{lstlisting}

\textbf{Requerimientos:}
\begin{enumerate}
    \item Debe leer el archivo y almacenar los datos correctamente.
    \item Debe usar \texttt{fscanf(file, "\%d \%f \%f", \&id, \&distancia, \&peso)} para leer los datos del archivo con el formato especificado.
    \item Filtre y muestre solo los envíos cuyo peso sea superior al umbral pasado por parámetro.
    \item Cuente la cantidad de envíos que superan el umbral e imprima el resultado.
\end{enumerate}

\section*{Ejercicio 3}
Implemente un programa que reciba como parámetro un archivo \texttt{input.in} y genere una codificación por tramos de caracteres (RLE - Run-Length Encoding).

\textbf{Ejemplo de comando:}
\begin{lstlisting}[numbers=none]
$ ./rle_encode input.in
\end{lstlisting}

\textbf{Ejemplo visual de funcionamiento:}
\begin{lstlisting}[numbers=none]
Entrada (en archivo): XXYYYYZZZZ
Salida (consola): X2Y4Z4
\end{lstlisting}

\textbf{Requerimientos:}
\begin{enumerate}
    \item Cargue el contenido del archivo pasado como argumentos del main.
    \item El programa debe validar que el archivo de entrada no esté vacío antes de proceder.
    \item Almacene la cadena codificada en un \textit{buffer}, usando el formato carácter seguido de cantidad.
    \item Imprima en pantalla el ``Ratio de Compresión'' (Tamaño Original / Tamaño Comprimido).
    \item Libere correctamente la memoria dinámica utilizada.
\end{enumerate}

\section*{Criterios de Evaluación}
\begin{itemize}
    \item \textbf{Gestión de Memoria:} Uso correcto de \texttt{malloc/free} y ausencia de fugas.
    \item \textbf{Robustez:} El programa no debe fallar si el archivo no existe o los argumentos son insuficientes.
    \item \textbf{Claridad:} Código bien estructurado y documentado en lugares clave.
\end{itemize}
