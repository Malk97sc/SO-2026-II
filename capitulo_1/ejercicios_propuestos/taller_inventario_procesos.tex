\section*{Introducción}
Este taller es una continuación directa del ejercicio de reportes de estaciones meteorológicas. En esta etapa, el procesamiento ya no será puramente secuencial. Aplicaremos \texttt{fork()} para que cada estación sea analizada simultáneamente por un proceso independiente.

\section*{Descripción del Problema (Fase II)}
La red meteorológica ha solicitado un análisis por humedad. Cada estación debe generar un reporte donde sus mediciones estén ordenadas de forma descendente según su humedad.

Para ello, su programa deberá implementar la siguiente lógica:

\subsection*{1. Proceso Padre}
\begin{itemize}
    \item Recibir y validar el nombre del archivo índice (\texttt{estaciones.idx}) desde la línea de comandos.
    \item Leer el archivo de índice para determinar el número total de estaciones ($N$) y almacenar los nombres de sus archivos de datos.
    \item Crear exactamente \textbf{$N$ procesos hijos}. Cada proceso hijo debe estar asociado a una estación específica según su orden de creación.
    \item Esperar la finalización de todos los hijos antes de terminar su propia ejecución.
\end{itemize}

\subsection*{2. Procesos Hijos}
Cada hijo, de forma independiente, deberá realizar lo siguiente:
\begin{itemize}
    \item Abrir el archivo \texttt{.dat} que le corresponde.
    \item Almacenar las mediciones en un vector dinámico de estructuras.
    \item Ordenar las mediciones por humedad utilizando un algoritmo de ordenamiento.
    \item Mostrar por consola las mediciones ordenadas, indicando claramente a qué estación pertenecen.
\end{itemize}

\section*{Apoyo Técnico}

\subsection*{Algoritmo de Ordenamiento}
Para cumplir con el reporte por humedad, puede elegir el algoritmo de ordenamiento que considere apropiado (ej. \textit{Bubble Sort}, \textit{Quicksort}). Lo fundamental es que el resultado mostrado por consola sea correcto.

\subsection*{Control de Identidad}
A diferencia de los talleres anteriores donde solo había un hijo, aquí debe asegurar que el padre cree un bucle para generar los $N$ hijos, y que cada hijo sepa exactamente qué archivo procesar basándose en el índice de dicho bucle.

\section*{Criterios de Evaluación}
\begin{itemize}
    \item Correcta gestión de la jerarquía de procesos.
    \item Uso apropiado de \texttt{wait()} para la sincronización.
    \item Almacenamiento dinámico de la información mediante vectores de estructuras.
    \item Ordenamiento preciso de los registros por humedad.
\end{itemize}
