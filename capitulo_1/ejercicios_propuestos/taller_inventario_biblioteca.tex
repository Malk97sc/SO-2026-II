\section*{Introducción}
El manejo eficiente de archivos es una habilidad fundamental para cualquier programador de sistemas. En este taller, implementará una herramienta que procese un inventario distribuido en múltiples archivos. El objetivo es leer un archivo índice que contiene los nombres de otros archivos de datos y procesar cada uno de forma secuencial.

\section*{Descripción del Problema}
Usted ha sido contratado para consolidar reportes de estaciones meteorológicas. La información se encuentra organizada de la siguiente manera:

\subsection*{1. Archivo de Índice }
El archivo \texttt{estaciones.idx} lista las estaciones activas. Su formato consiste en un entero inicial $N$ (número de estaciones), seguido de $N$ nombres de archivos de datos correspondientes.
\begin{lstlisting}[title=Ejemplo de sedes.idx]
3
estacion_costa.dat
estacion_sierra.dat
estacion_rio.dat
\end{lstlisting}

\subsection*{2. Archivos de Sede}
Cada archivo de estación contiene sus mediciones. El formato es un entero $M$ (número de mediciones), seguido de $M$ líneas con el formato: \texttt{Fecha,Temperatura,Humedad}.
\begin{lstlisting}[title=Ejemplo de sede\_norte.dat]
2
2026-08-20,31.5,78
2026-08-21,30.0,81
\end{lstlisting}

\section*{Objetivos del Taller}
Su programa deberá realizar las siguientes tareas en orden estrictamente secuencial:

\begin{enumerate}
    \item Recibir el nombre del archivo índice por la línea de comandos (\texttt{argv[1]}).
    \item Leer el archivo índice y cargar los nombres de los archivos de cada estación en un vector dinámico de strings.
    \item Recorrer dicho vector y, para cada nombre de archivo:
    \begin{itemize}
        \item Abrir el archivo de la estación.
        \item Leer cada medición (usando \texttt{fscanf} o \texttt{fgets}).
        \item Imprimir un resumen por consola con el nombre de la estación, el total de mediciones y su temperatura promedio.
    \end{itemize}
    \item Liberar toda la memoria dinámica utilizada antes de finalizar.
\end{enumerate}

\section*{Criterios de Evaluación}
\begin{itemize}
    \item Uso correcto de \texttt{malloc} y \texttt{free} para el manejo de strings.
    \item Apertura y cierre adecuado de todos los descriptores de archivos.
    \item Validación de argumentos de entrada.
\end{itemize}
